# 优化首页导航、活动展示与必填标注

## Goal

降低首页首屏与今日活动区域的视觉噪音，使导航层级更清楚，并让公开投稿者和管理员在填写前即可识别所有必填字段。

## Background

- 首页已经把地区选择移入公共导航，但地区入口与主导航仍共处右侧，桌面端的“首页 / 活动 / 投稿”没有真正居中。
- Hero 下方仍有“热门活动 / 今日活动”页内锚点；页面只有两个连续内容区，锚点的导航价值不足。
- 今日列表自身存在底边，CTA 容器又增加顶边，因此两者之间出现两条分割线。
- `listHomepageDiscovery()` 当前返回全部当日本地活动，极端情况下首页会过长。
- 公开投稿与管理员新建页已经在 HTML 和服务端校验中区分必填字段，但标签未显式显示“必填”。

## Requirements

### R1. 简化首页内容导航

- 删除 Hero 下方“热门活动”和“今日活动”两个页内锚点按钮及其不再使用的图标导入。
- 保留 Hero 内的“查看主推荐”操作、热门区的 `3 / 7 / 30` 时间窗口和底部“继续浏览本地活动”CTA。
- 不改变热门活动的本地/全国榜单、排序或统计口径。

### R2. 调整公共导航对齐

- 桌面端公共导航采用三段结构：站名靠左，“首页 / 活动 / 投稿”在导航胶囊内几何居中，首页地区选择靠右。
- 地区选择仍只在首页出现；其他公开页面不得出现空的可交互地区入口。
- 移动端继续显示站名、首页地区选择和菜单按钮，三者不得重叠或产生页面级横向滚动。
- 保持现有路由 active 状态、移动菜单、地区 Drawer、地区持久化、Escape 关闭和焦点恢复合同。

### R3. 今日活动最多展示 10 场

- 首页今日查询在 D1 层使用 `LIMIT 10`，而不是先加载全部结果后在页面切片。
- 保持现有日期覆盖条件、地区过滤、稳定排序，以及主推荐可同时出现在今日列表中的行为。
- 今日区说明文案不得继续声称展示“全部活动”；CTA 仍精确指向 `/events?city=<divisionCode>`，供用户继续浏览和筛选。

### R4. 去除重复分割线

- 今日列表或空状态与 CTA 之间只保留一条可见分割线。
- CTA 的间距和可点击区域保持清楚，不以第二条边线制造额外层级。

### R5. 标注公开投稿必填项

- 公开投稿页显式标注以下必填字段：标题、类型、规模、地区、地点、开始日期、结束日期、活动来源链接、投稿联系方式。
- 标注使用可见中文“必填”，不能只依赖颜色、星号、placeholder 或浏览器提交后的错误提示。
- 选填字段和 Turnstile 行为保持不变；字段名、POST 路由和服务端校验合同不变。

### R6. 标注管理员新建活动必填项

- 管理员新建页显式标注：活动名称、类型、规模、地区、场馆、开始日期、结束日期、来源链接、投稿联系方式，以及新建发布所要求的至少一个规范标签。
- `AdminEventForm` 继续作为新建/编辑的共享表单；必填标注通过页面级配置只在新建流程启用，避免顺带改变编辑页范围。
- 管理员新建 API、立即发布行为、标签校验和审计写入保持不变。

## Acceptance Criteria

- [ ] AC1：桌面端站名靠左、主导航居中、首页地区选择靠右；390px、768px、1440px 宽度均无重叠和页面级横向滚动。
- [ ] AC2：首页 Hero 后不再渲染“热门活动 / 今日活动”锚点按钮，热门与今日 section 顺序不变。
- [ ] AC3：今日查询 SQL 含 `LIMIT 10`，仍含 `start_date <= today <= end_date`、原地区过滤和原稳定排序，且不使用 `EVENT_ENDED_CLAUSE`。
- [ ] AC4：首页最多渲染 10 条今日本地活动；底部 CTA 仍仅携带当前 `city` 查询参数。
- [ ] AC5：今日列表或空状态与 CTA 之间只有一条可见分割线。
- [ ] AC6：公开投稿页的 9 个服务端必填字段均显示中文“必填”，所有选填字段不显示该标注。
- [ ] AC7：管理员新建页的 9 个基础必填字段和规范标签均显示中文“必填”；管理员编辑页不新增这些页面级标注。
- [ ] AC8：地区 Drawer、地区偏好恢复、导航 active 状态、热门统计、表单字段名、API 路由与现有校验行为无回归。
- [ ] AC9：Prettier、Lint、TypeScript、单元测试、生产构建和 `git diff --check` 全部通过；浏览器完成三档视口检查。

## Out Of Scope

- 不改变主推荐的“今日至未来 14 天且尚未结束”选择合同。
- 不改变热门榜单的 3/7/30 日窗口、每榜最多 5 条或独立访客统计。
- 不改变活动目录筛选、分页或 CTA 查询参数。
- 不修改表单实际必填规则、数据库 schema、迁移、API 响应或管理员编辑流程。
- 不引入新的 CSS/UI 运行时依赖。

## Blocking Questions

无。
