# PRD：优化首页地区与本地活动流

## 目标

降低地区选择在首页的视觉权重，减少“附近活动”和“本地热门”的信息重复，并把首页向下浏览的主线改为“热门活动 -> 今日活动 -> 进入活动页继续筛选”。用户首次确定地区后，后续访问只需在主导航中看到一个紧凑的地区入口。

## 已确认事实

- 首页通过 `resolveSelectedDivision()` 从查询参数、Cloudflare 地理信息或默认地区解析当前地区；`CitySelector.svelte` 会把选择写入 `localStorage` 并带 `city` 查询参数刷新目标页面。
- 当前首页的 `listHomepageNearby()` 同时查询一个主推荐、最多四个进行中活动和未来三个日期分组；该合同不能表达“今日全部活动”。
- `listHomepagePopularity()` 已同时提供本地和全国近 `3 / 7 / 30` 日热门活动，每列最多五条。
- `/events` 已支持 `city`、`active`、`starts` 和其他筛选参数；只携带 `city` 时会显示该地区未结束活动并允许用户继续筛选。
- 公开主导航由 `Layout.astro` 和 `PublicMobileNav.svelte` 组成，当前站名前有一个圆形“同”标志。

## 需求

### R1：紧凑地区入口

- 删除首页首屏后的大型“浏览地区”块。
- 在首页的公开主导航中增加紧凑地区入口，显示当前地区的短标签并提供清晰的地图定位图标和可访问名称。
- 激活入口后复用现有地区三级选择与持久化逻辑；选择地区后仍导航到 `/?city=<divisionCode>`。
- 桌面和约 390px 移动视口都必须保留品牌、地区入口和主导航操作，不能发生遮挡或页面级水平溢出。
- 地区入口只在首页出现，避免在详情、投稿和 404 页面引入无上下文的页面跳转。

### R2：首页发现顺序

- 保留完整热门活动模块，包括本地热门、全国热门和 `3 / 7 / 30` 时间范围控制。
- 删除现有“附近活动”模块及其进行中、未来日期分组。
- 首页内容顺序调整为：主推荐、热门活动、今日活动。
- 首页锚点导航相应调整为“热门活动”和“今日活动”。

### R3：今日全部本地活动

- 今日活动使用中国时区自然日期，显示当前地区内所有在今天覆盖有效日期范围且状态为已发布的活动。
- 今日活动不得受“是否已在今天结束”的当前时刻判断影响；只要 `start_date <= today <= end_date` 就属于今日活动。
- 今日活动不设置首页数量截断，使用稳定的紧凑活动行逐条呈现，并提供加载失败和空状态。
- 主推荐从今天起 14 天内仍未结束的活动中选择，让今天正在举行的重要活动也有机会占据首屏推荐位。
- 当主推荐属于今日活动时，它仍保留在“今日活动”完整列表中；这种重复是有意的，今日列表不得因此遗漏活动。
- 今日活动列表末尾提供一个进入活动页的按钮，目标为 `/events?city=<divisionCode>`；不得额外预设日期、类型、规模或排序，让用户在活动页继续筛选本地接下来发生的活动。

### R4：导航品牌简化

- 删除公开主导航中站名前的圆形“同”标志。
- 保留“同频点”站名、桌面口号、当前页面状态和现有首页/活动/投稿入口。
- 不修改管理后台品牌标志或管理导航。

### R5：兼容与质量

- 不改变 `/events` 查询参数合同、热门活动统计合同、地区持久化键、数据库 schema、Cloudflare 绑定或管理后台行为。
- 继续使用 Tailwind v4、Flowbite Svelte、Flowbite Svelte Icons 和共享 `SidePanel`/`CitySelector` 边界。
- 保持亮暗模式、键盘焦点、Drawer `Escape` 关闭与关闭后焦点恢复、减少动效和图片 fallback。

## 验收标准

- [ ] AC1：首页不再出现大型“浏览地区”块；当前地区可从主导航中的紧凑入口查看和修改。
- [ ] AC2：公开导航站名前不再显示圆形“同”标志，其他公开导航入口与 active 状态不回归。
- [ ] AC3：首页顺序为主推荐、热门活动、今日活动，不再渲染旧“附近活动”日期分组。
- [ ] AC4：热门模块继续同时呈现本地/全国排行及 `3 / 7 / 30` 切换，URL 保留当前 `city`。
- [ ] AC5：今日活动包含当前地区内所有 `start_date <= today <= end_date` 的已发布活动，包括今天较早结束的活动；列表不做首页数量截断。
- [ ] AC6：今日列表底部按钮准确指向 `/events?city=<当前地区>`，且不附带其他筛选参数。
- [ ] AC7：今天正在举行且当前尚未结束的活动可成为主推荐；若同时出现在今日完整列表中，不视为重复缺陷。
- [ ] AC8：无今日活动、地区解析失败、数据库查询失败和无可用主推荐时均有明确且不遮挡的状态。
- [ ] AC9：约 390x844、768x1024、1440x1000 下导航、地区入口、热门列表和今日列表无水平溢出、文本遮挡或不可触达操作。
- [ ] AC10：`corepack pnpm lint`、`corepack pnpm exec tsc --noEmit`、`corepack pnpm test`、`corepack pnpm build` 与 `git diff --check` 通过。

## 范围外

- 修改热门值定义、访客去重或 `3 / 7 / 30` 时间窗口。
- 修改活动目录默认筛选、分页或新增“只看今天”产品模式。
- 自动请求浏览器定位权限、增加地图服务或新增全局地理状态框架。
- 修改管理后台、活动详情、投稿流程、数据库 schema 或 API 响应。
