# 为管理员提供批量创建活动功能

## Goal

让已认证管理员通过标准 CSV 工作流一次创建多条活动，减少重复填写和逐条提交成本，同时保持现有单条创建活动的数据质量、立即发布规则和审计能力。

## Background

- 项目已经提供 `/admin/events/new` 和 `POST /api/admin/events`；管理员创建的活动会立即发布。
- 现有管理员表单校验覆盖活动类型、规模、区县代码、日期与时间顺序、HTTP(S) URL、必填字段和规范标签。
- 现有单条创建使用 D1 `batch()` 原子写入活动、标签关系和 `create` 审计记录。
- Cloudflare D1 免费计划每次 Worker 调用最多执行 50 条查询，整个批次最长执行 30 秒；批次内任一语句失败会回滚整个序列。
- 项目当前没有 CSV 解析依赖或通用自动化测试脚本。

## Requirements

- R1. 只有通过现有管理员认证的用户可以访问批量创建页面、模板和相关 API。
- R2. 管理后台必须提供可发现的“批量导入”入口，以及带固定中文列名的 UTF-8 CSV 模板下载；页面提供字段取值说明。
- R3. 首版只支持 CSV 文件，不支持 XLSX、JSON 粘贴或页面内动态添加多条活动；单批必须包含 1 至 20 条活动，客户端和服务端都执行数量限制。
- R4. CSV 覆盖现有管理员单条创建的全部活动字段。标签单元格使用中文顿号 `、` 分隔；逗号、引号和多行文本必须由成熟 CSV 解析库按标准引用规则处理，不允许手写 CSV 拆分器。
- R5. 选择文件后必须先显示记录总数和逐条预览，不得立即写入数据库；管理员明确确认后才能创建。
- R6. 每条记录必须复用现有管理员单条创建的字段校验和规范化。文件结构或记录无效时，错误必须定位到 CSV 记录序号和中文字段名，整批不得提交。
- R7. 预览时以规范化后的“活动名称 + 开始日期 + 场馆”检测 CSV 内及现有数据库中的疑似重复活动。疑似重复只显示警告，管理员明确确认后仍可创建，系统不得静默跳过。
- R8. 提交时服务端必须重新解析、校验和检查重复项，不信任浏览器预览数据；新增的未确认警告必须阻止提交并要求重新确认。
- R9. 批量创建必须整批成功或整批失败。所有活动、规范标签、标签关系和审计记录在同一 D1 事务边界内提交，任一写入失败则全部回滚。
- R10. 成功创建的活动全部立即发布，并分别生成包含 CSV 记录序号和批次来源的 `create` 审计记录。
- R11. 成功状态显示创建数量，并列出活动名称、ID 和编辑链接；首版不生成结果文件。
- R12. 现有单条创建、编辑、审核、下线、重新发布和普通用户投稿行为保持不变。

## Acceptance Criteria

- [ ] AC1. 已认证管理员可从桌面和移动管理导航进入批量导入页面；未认证页面/API 请求仍被现有鉴权拦截。（R1、R2）
- [ ] AC2. 管理员可下载 Excel/WPS 可读的 UTF-8 CSV 模板，并上传包含 1 至 20 条活动的文件。（R2、R3）
- [ ] AC3. 空文件、超过 20 条记录、错误列名、缺列、多列、无效 UTF-8 或语法错误的 CSV 会显示明确错误且不写入数据库。（R3、R4、R6）
- [ ] AC4. 标准 CSV 引用中的逗号、引号和多行文本能正确解析；标签按 `、` 分隔并遵守现有标签数量、长度和去重规则。（R4、R6）
- [ ] AC5. 上传后先显示逐条预览；确认前数据库没有新增活动、标签关系或审计记录。（R5）
- [ ] AC6. 字段无效时，预览按记录序号和字段显示错误；任一记录有错误时确认按钮不可用，整批无写入。（R6）
- [ ] AC7. CSV 内或数据库中存在疑似重复活动时，预览标出匹配来源；管理员确认警告后仍可创建，提交阶段出现的新警告会要求重新确认。（R7、R8）
- [ ] AC8. 确认期间任一数据库操作失败时，所有活动、标签关系和审计记录全部回滚。（R9）
- [ ] AC9. 成功后所有活动均为 `published`，每条活动都有规范标签和一条批量创建审计记录；页面列出名称、ID 和编辑入口。（R10、R11）
- [ ] AC10. 现有单条创建和其他活动管理流程通过回归验证。（R12）

## Out of Scope

- XLSX、JSON 粘贴、页面内多行编辑器或超过 20 条活动的异步导入。
- 允许有效记录先创建、无效记录后修正的部分成功模式。
- 以疑似重复为由自动跳过、合并或硬性阻止活动。
- 导入结果 CSV/XLSX 下载、历史导入批次页面或后台导入任务队列。
- 修改普通用户投稿、活动编辑或既有发布状态流程。
